# Setting Up My Homelab

This repository documents the systems in my Proxmox homelab. Each guide has its own folder, with setup steps, screenshots, validation, and troubleshooting together on one page.

## Guides

| Area | Guide | Covers |
| --- | --- | --- |
| Networking | [OPNsense VLANs with one NIC](docs/networking/README.md) | Internal VLAN bridge, six networks, DHCP, firewall rules, and remote access |
| Monitoring | [Prometheus and Grafana on Proxmox](docs/monitoring/README.md) | Exporters, dashboards, alerts, and troubleshooting |

Each guide's screenshots appear beside the relevant steps. Future guides, including Pi-hole, can be added in their own folder under `docs/` and linked here.
